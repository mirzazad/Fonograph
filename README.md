# Fonograph

TEFAS verisinden üretilen piyasa paneli.

**Canlı sayfa:** https://mirzazad.github.io/Fonograph/

## Sekmeler

- **PYŞ Dağılım** — portföy yönetim şirketleri bazında varlık dağılımı, iki şirketi yan yana karşılaştırma
- **Fon Akımları** — fon bazında kümülatif net giriş/çıkış ve fiyat serisi
- **Fon Karşılaştırma** — kategori bazında getiri ve varlık dağılımı tabloları

## Veri kaynakları

| Kaynak | Ne için |
|---|---|
| [TEFAS](https://www.tefas.gov.tr/) | Günlük fon fiyatı, portföy dağılımı, toplam değer |
| [SPK](https://spk.gov.tr/kurumlar/portfoy-yonetim-sirketleri/portfoy-degerleri) | PYŞ bazında yönetilen toplam portföy büyüklüğü (aylık) |
